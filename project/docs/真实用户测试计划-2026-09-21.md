# 真实用户测试计划

日期：2026-09-21

## 分工

- 主代理：确定范围、验收标准与风险边界，复核报告和改动。
- Explorer：只读确认入口与现有测试环境（已完成）。
- Luna Executor：执行浏览器用户操作，记录证据，编写测试报告；不修改业务代码。

## 环境与边界

- 线上入口：http://151.246.186.93/#/。验证实际可见页面，不更改已有正式账号的数据。
- 本地入口：http://127.0.0.1:5177。通过 project/tooling/preview-fixture.mjs 提供独立内存服务，只使用测试账号及合成单词。
- 本地测试不能证明线上 MySQL、跨设备同步或生产部署通过。

## 执行顺序与验收

1. 首次访问与登录：检查访客提示、表单反馈、测试账号登录及页面导航。
2. 词库准备：导入合成内容，检查数量、搜索命中及无结果提示。
3. 学习闭环：新学、显示答案、作答、拼写和结果反馈。
4. 数据状态：刷新后检查进度；切换两个测试账号检查词库可见性。
5. 手机显示：检查窄屏下主要控件、滚动和布局，结束后恢复尺寸。
6. 报告：逐项标明通过、失败或未测；缺陷附环境、步骤、期望、实际和优先级。

## 最终复核

检查报告与浏览器证据是否一致，确认无业务源码或正式数据变动；对重要缺陷做必要的定向复核。仅凭代码推断的风险不得描述为已复现缺陷。
