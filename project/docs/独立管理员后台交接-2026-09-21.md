# 独立管理员后台交接（2026-09-21）

## 已完成

- 管理员后台改为独立页面：`/admin.html`，拥有独立登录、权限检查、页头和退出流程。
- 学习前台不再嵌入账号管理；旧地址 `/#/admin` 只显示迁移说明并链接到新后台。
- 普通账号访问后台时显示明确的无权限页面，不再看到管理界面外壳或接口报错。

- 创建账号成功后清空邮箱、用户名和密码输入框。
- 编辑确认说明、返回学习前台链接已修正。
