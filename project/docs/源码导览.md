# 源码导览

这份项目是 React + Vite + Tailwind 的本机优先背词网站。日常只需要进入 `app/` 修改网站；`project/` 中的内容是说明、部署与历史资料。

## 目录结构

```text
cet-4-6 project/
├── app/                         # 网站源码：日常开发只打开这里
│   ├── index.html               # 网页壳
│   ├── src/
│   │   ├── main.tsx             # 浏览器启动入口
│   │   ├── App.tsx              # 主页面、路由与学习流程
│   │   ├── types.ts             # 数据类型
│   │   ├── pages/               # 学习统计、架构图等独立页面
│   │   ├── data/                # localStorage、复习、导入导出、统计规则
│   │   └── styles/              # 响应式与夜间模式样式
│   ├── public/                  # 图标、PWA 清单、Service Worker
│   └── tests/                   # 数据、备份、复习与统计测试
├── project/                     # 工程资料：不参与网页运行
│   ├── docs/                    # 源码导览、前端精简交接、1Panel 部署交接、UI 提示词
│   ├── deploy/1panel/           # 以后部署到 1Panel 的示例
│   └── archive/supabase/        # 停用的历史 SQL，仅供参考
├── project/tooling/             # Vite、Tailwind、PostCSS、TypeScript 配置
│   ├── vite.config.mjs          # 指向 app/ 的构建配置
│   ├── tailwind.config.js       # Tailwind 扫描配置
│   └── tsconfig*.json           # TypeScript 配置
└── package.json                 # 启动、测试、构建命令
```

## 从哪里开始看

| 想修改什么 | 优先打开 |
| --- | --- |
| 首页、背词流程、词库、个人页 | `app/src/App.tsx` |
| 今日复习计划、学习统计图 | `app/src/pages/StatisticsPage.tsx`、`app/src/data/statisticsService.ts` |
| 单词导入、删除、导出、本地备份 | `app/src/data/localStore.ts` |
| 以后替换成服务器 API | `app/src/data/repository.ts` |
| 手机/电脑端排版、夜间模式 | `app/src/styles/index.css` |
| 单词和复习记录的数据字段 | `app/src/types.ts` |
| 本地数据规则测试 | `app/tests/storage.test.mjs` |

## 当前数据边界

- 当前没有数据库：词库、学习记录和统计事件都保存在浏览器 localStorage。
- `app/src/data/repository.ts` 是页面和数据之间的边界。以后接 1Panel + Node API + MySQL 时，优先替换这里的实现，页面组件可以继续复用。
- `app/src/data/localStore.ts` 中的 TSV、备份和复习规则需要保持兼容；迁移服务器前先导出本机备份。
- `project/archive/supabase/` 只保存历史参考，里面的 SQL 不能导入 MySQL。
