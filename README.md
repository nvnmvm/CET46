# CET 真题个人背单词系统

这是根据 MVP v1.0 项目单实现的前端可运行版本。当前采用浏览器 `localStorage` 作为本机数据仓库，因此不需要数据库账号也能完成 TSV 导入、今日复习、认词、拼写和刷新后进度保留。

2026-09-13 更新开发路线：后续部署到自有服务器，以 1Panel 管理静态网站、后端服务与 MySQL。保留 React 源码，构建后上传完整 `dist/`（HTML + CSS + JavaScript）；通过新增后端 API 访问数据库。当前仍是本地存储版本，尚未实现服务器账号或云端同步。阶段流程与验收标准见 [交接文档.md](./project/docs/交接文档.md)。

刚接手项目时，先看 [源码导览](./project/docs/源码导览.md)。如果当前任务是整理前端并在完成后上线，先按 [前端精简与部署交接文档](./project/docs/前端精简与部署交接文档.md) 分阶段执行，通过全部回归后再按 [1Panel 部署交接文档](./project/docs/部署交接文档.md) 上线。

## 已实现

- 中文、手机优先的首页、复习、导入、词库、个人、本地登录页面
- 批量 TSV 与手动添加两种入口；统一使用含 IPA 音标的 8 列格式，并支持本地 `.tsv/.txt` 文件
- 导入页内置可复制的 GPT 图片识别提示词，包含 `marked` 与 `added` 两个正确输出示例
- 同词去重：不创建第二条词，保留既有进度，`marked` 优先
- 新词立即到期；每轮最多 20 词，避免一次任务过载
- 首页“今日学习任务”支持修改每日组数（1—20 组）和每组词数（1—20 个），到期旧词优先；设置只改变后续任务上限，不重置学习进度
- 主动回忆、答案后自检、认词错词队尾回炉、逐词拼写订正
- 复习过程自动保存草稿；刷新或离开后可继续上次进度，也可重新开始本轮
- 自动映射“重学 / 困难 / 稳固 / 轻松”四档结果，采用透明固定 stage 间隔
- Recognition / Spelling 独立评分、浏览器英文发音与词库记忆状态筛选
- “已斩”独立状态：从每日复习移除但保留全部词条和进度，支持即时撤销与重新恢复
- 词库支持导出和恢复本机 JSON 备份；即时撤销斩词不会改变原记忆阶段和复习日期
- 顶部主题按钮支持跟随系统、日间、夜间三种模式，并保存在当前设备
- 个人页用柱状图展示新词、记忆中、巩固中、已掌握、已斩五个记忆层次，并显示掌握率、今日完成和待处理数量
- 浏览器刷新后保存词库及复习进度
- PWA manifest、离线应用壳和 iPhone 主屏图标
- GitHub Actions 测试及构建配置；`project/archive/supabase/` 仅保留停用的历史迁移草案

## 本地启动

需要 Node.js 20.19+（本次验证使用 Node.js 24）和 pnpm。

```bash
pnpm install
pnpm dev
```

浏览器打开终端输出的本地地址。构建生产包：

```bash
pnpm build
pnpm preview
```

## TSV 格式

首行必须严格为（第 2 列为必填 IPA 音标）：

```text
word\tphonetic\tmeaning\tphrase\tsentence\tsentence_cn\tsource\ttype
```

数据行示例：

```text
alleviate\t/əˈliːvieɪt/\t缓解；减轻\talleviate financial pressure\tThe policy could alleviate financial pressure.\t这项政策可以缓解经济压力。\t2025-12 CET6 阅读1\tmarked
```

`phonetic` 必填，并须使用 `/.../` 格式；`type` 仅允许 `marked` 或 `added`。导入前会对 `word` 执行 `trim()` 和小写化。为保证学习卡片信息完整，省略音标的旧 7 列格式不再接受；同词重新导入时内容会更新，但学习进度不重置。

导入页面提供“照片 + GPT 提示词 → 复制 TSV → 预览导入”的引导和一键复制按钮。解析器会自动清理常见 GPT 代码框与 UTF-8 BOM，并校验单词词形、中文释义和单批大小；手动添加同样要求填写 IPA 音标与中文释义。

## 当前本机模式的边界

- 登录页只生成当前浏览器内的学习档案，不发送邮箱，也不验证密码。
- 数据仅保存在当前浏览器；清除网站数据或更换设备后不会自动保留。
- `.env.example` 现在改为服务器 API / 后端配置占位，当前前端不会读取；MySQL 密码只配置在后端。

## 当前学习机制

一次学习分为三个阶段：先只看英文进行主动回忆；没想起或核对错误的词会排到本轮队尾，直到回忆正确；随后只看中文完成英文拼写，拼错时必须隐藏答案并在当前词订正成功后才能继续。

首页“今日学习任务”右上角的“修改组数”可设置每天 1—20 组；其下方的“修改每组词数”可设置每组 1—20 个词，默认每组 10 个。设置会保存在当前浏览器档案中，并限制今日待处理队列总量；每轮按每组词数切分，单组最多 20 个词。已有未完成复习草稿会继续按原队列恢复，不会因为修改计划而丢失。

系统综合两阶段表现自动给出调度等级：

- `again`（重学）：理解阶段曾没想起或核对错误，stage -2，最低为 0；
- `hard`（困难）：理解一次通过、但拼写曾错误，stage 不变；
- `good`（稳固）：理解和拼写均一次通过，stage +1；
- `easy`（轻松）：stage 已达到 3，且两项历史分数均至少为 3，本轮又一次通过，stage +2。

最终 stage 对应下一次复习间隔为 `1 / 2 / 4 / 7 / 15 / 30 / 60` 天。理解与拼写分数分别根据本轮是否出错执行 `-1 / +1`，取值限制在 0–5。

“已掌握”由 stage 自动判断，仍会在较长间隔后复习；“已斩”是用户主动操作，不再进入到期队列。斩词不是删除，可在词库“已斩”筛选中恢复。恢复时保留历史评分，将 stage 降至最多 2 并立即重新到期，避免忘记后仍沿用过长间隔。
